# Tribu

La cuenta compartida de tu grupo, en dólares.

Tribu es para amigos, parejas, familias y cualquier grupo que comparte gastos. Cada tribu vive en un
link: armás la tribu, la compartís en el chat y cada uno anota lo que pagó.

- **Anotar:** cargás un gasto en cualquier moneda y elegís cómo se reparte.
- **Quedar a mano:** Tribu te dice quién le pasa a quién y cuánto, con el menor número de pagos.
- **Juntar:** la vaquita del grupo, para los gastos de todos.
- **Recordar:** un aviso amable para el que todavía no pasó lo suyo.

## Desarrollo

```bash
pnpm bootstrap   # instala las dependencias (no uses `pnpm install` a secas)
pnpm dev         # levanta la app en http://localhost:3000
```

Antes de subir cambios: `pnpm typecheck && pnpm test`.
